Condiciones del servicio

ScientificBrain Cloud Connector Desarrollado por Innova Space Education SpA Actualizadas: 20-09-2026

Estas Condiciones regulan el uso de ScientificBrain Cloud Connector, una integración destinada a facilitar la interacción autorizada con recursos de Google Cloud mediante Model Context Protocol (MCP), OAuth 2.0 e IAM.

1. Aceptación

Al autorizar y utilizar ScientificBrain Cloud Connector, el usuario declara haber leído y aceptado estas Condiciones, los Términos de uso y la Política de Privacidad.

2. Finalidad del servicio

El servicio permite realizar consultas, diagnósticos y, cuando corresponda, operaciones administrativas sobre recursos de Google Cloud a los que el usuario ya tenga acceso. ScientificBrain Cloud Connector no crea por sí mismo privilegios adicionales ni evita las restricciones definidas por Google Cloud IAM.

3. Autorización y responsabilidad del usuario

  • El usuario debe utilizar una cuenta de Google que esté autorizado a emplear.
  • El usuario es responsable de los permisos que concede y de revisar periódicamente el acceso OAuth e IAM.
  • Las operaciones que modifiquen infraestructura, permisos, servicios, configuraciones o datos deben ser solicitadas por un usuario con autoridad suficiente.
  • El usuario no debe utilizar la integración para vulnerar sistemas, eludir controles de acceso, acceder a datos sin autorización o realizar actividades ilícitas.

4. Alcance OAuth

La integración puede solicitar el alcance https://www.googleapis.com/auth/cloud-platform. Este alcance es amplio, por lo que el usuario debe mantener sus roles IAM bajo el principio de mínimo privilegio y utilizar identidades separadas cuando resulte apropiado.

5. Disponibilidad

El servicio depende de plataformas y API de terceros, incluidas las de Google Cloud y el cliente MCP utilizado. Puede experimentar cambios, interrupciones, límites de cuota o indisponibilidad ajenos al control de Innova Space Education SpA.

6. Cambios y operaciones sobre infraestructura

Las acciones sobre Google Cloud pueden producir efectos reales, incluidos despliegues, cambios de configuración, generación de costos o modificaciones de acceso. El usuario debe revisar cuidadosamente cualquier operación sensible antes de autorizarla.

7. Costos de terceros

El uso de Google Cloud puede generar cargos en la cuenta o proyecto del usuario. ScientificBrain Cloud Connector no modifica las tarifas de Google ni asume los costos derivados de los servicios cloud activados o consumidos por el usuario.

8. Propiedad intelectual

ScientificBrain Cloud Connector, su documentación y sus elementos propios pertenecen a Innova Space Education SpA o se utilizan conforme a las licencias aplicables. Google Cloud, Google y otras marcas de terceros pertenecen a sus respectivos titulares.

9. Servicios de terceros

El uso de Google Cloud y de cualquier cliente MCP de terceros se rige adicionalmente por los términos, políticas, límites y condiciones de dichos proveedores. Innova Space Education SpA no declara afiliación, patrocinio ni respaldo por parte de Google u OpenAI.

10. Suspensión o restricción

El acceso puede suspenderse o limitarse cuando exista riesgo de seguridad, uso no autorizado, incumplimiento de estas Condiciones, requerimiento legal o necesidad técnica razonable.

11. Limitación de responsabilidad

En la medida permitida por la legislación aplicable, ScientificBrain Cloud Connector se proporciona como una herramienta de apoyo operativo. El usuario debe validar acciones críticas y mantener respaldos, controles de acceso y procedimientos de recuperación apropiados para su infraestructura.

12. Cambios en las condiciones

Estas Condiciones pueden modificarse para reflejar nuevas funciones, cambios técnicos, regulatorios o de proveedores. La versión vigente estará publicada en esta URL con su fecha de actualización.
