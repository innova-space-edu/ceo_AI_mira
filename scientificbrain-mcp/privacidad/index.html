Política de privacidad

ScientificBrain Cloud Connector Desarrollado por Innova Space Education SpA Actualizada: 20-09-2026

Esta Política de Privacidad describe cómo ScientificBrain Cloud Connector utiliza información cuando una persona conecta un cliente autorizado con servicios de Google Cloud mediante OAuth 2.0.

1. Responsable

ScientificBrain Cloud Connector es desarrollado y administrado por Innova Space Education SpA, Chile. Para consultas sobre privacidad o ejercicio de derechos, puede escribir a contacto@innova-space-edu.cl.

2. Información y permisos utilizados

La aplicación puede trabajar con las siguientes categorías de información:

  • Datos básicos asociados a la autenticación OAuth necesarios para identificar la sesión autorizada.
  • Metadatos y recursos de Google Cloud a los que la cuenta autenticada ya tenga acceso.
  • Resultados de consultas, diagnósticos, registros y operaciones de administración solicitadas expresamente por el usuario.
  • Información técnica mínima necesaria para seguridad, diagnóstico y trazabilidad de la integración, cuando corresponda.

La configuración OAuth puede solicitar el alcance https://www.googleapis.com/auth/cloud-platform. El alcance no sustituye las políticas IAM: las acciones efectivas siguen limitadas por los permisos asignados a la identidad del usuario en Google Cloud.

3. Finalidades del tratamiento

  • Autenticar al usuario mediante Google OAuth 2.0.
  • Ejecutar consultas y acciones de Google Cloud solicitadas por el usuario.
  • Diagnosticar errores, despliegues, servicios y configuraciones.
  • Proteger la integración frente a abuso, acceso no autorizado o fallos técnicos.
  • Cumplir obligaciones legales aplicables.

4. Contraseñas y credenciales

Innova Space Education SpA no solicita la contraseña de la cuenta de Google. La autenticación se realiza mediante OAuth 2.0. Los tokens de autorización son gestionados por el flujo OAuth y por los servicios o clientes autorizados que participan en la conexión.

5. Compartición de datos

No vendemos datos personales ni información obtenida a través de las API de Google. La información puede ser procesada por proveedores indispensables para prestar la funcionalidad solicitada, como Google Cloud y el cliente MCP que el usuario haya elegido, sujeto a sus respectivas políticas, contratos y configuraciones de cuenta.

6. Google API Services User Data Policy

El uso de información recibida desde las API de Google se realizará de acuerdo con la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado cuando resulten aplicables.

7. Conservación

ScientificBrain Cloud Connector busca minimizar la conservación de información. Los datos derivados de operaciones se mantienen únicamente durante el tiempo necesario para ejecutar la solicitud, mantener seguridad y trazabilidad razonable, resolver incidencias o cumplir obligaciones legales. La información que permanezca en Google Cloud continúa sujeta a las políticas de retención del proyecto y del servicio de Google correspondiente.

8. Seguridad

Se utilizan mecanismos de autorización OAuth 2.0, controles IAM y principio de mínimo privilegio cuando sea técnicamente posible. Ningún sistema puede garantizar seguridad absoluta, por lo que los usuarios deben proteger sus cuentas, revisar sus permisos y evitar conceder acceso innecesario.

9. Revocación del acceso

El usuario puede revocar el acceso OAuth desde la configuración de seguridad de su cuenta de Google y también puede solicitar asistencia escribiendo a contacto@innova-space-edu.cl. La revocación impide nuevas operaciones que requieran la autorización revocada.

10. Servicios de terceros

ScientificBrain Cloud Connector puede interoperar con servicios de Google Cloud y con clientes MCP de terceros. El uso de esos servicios está sujeto adicionalmente a sus propios términos y políticas de privacidad. Innova Space Education SpA no declara afiliación, patrocinio ni respaldo por parte de Google u OpenAI.

11. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, los proveedores o las obligaciones legales. La fecha de actualización se publicará en esta misma página.
