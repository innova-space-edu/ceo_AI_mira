Términos de uso

ScientificBrain Cloud Connector Desarrollado por Innova Space Education SpA Actualizados: 20-09-2026

Estos Términos regulan el acceso y uso de ScientificBrain Cloud Connector, una integración desarrollada por Innova Space Education SpA para conectar clientes autorizados con recursos de Google Cloud mediante OAuth 2.0, controles IAM y, cuando corresponda, Model Context Protocol (MCP).

1. Uso autorizado

El usuario solo puede utilizar ScientificBrain Cloud Connector con cuentas, proyectos, organizaciones, carpetas, servicios y recursos de Google Cloud para los que disponga de autorización válida. El servicio no concede privilegios adicionales ni permite eludir las políticas IAM vigentes.

2. OAuth y autorización

El acceso a Google Cloud puede requerir un flujo OAuth 2.0 y el alcance https://www.googleapis.com/auth/cloud-platform. La concesión de un alcance OAuth no implica que todas las operaciones estén habilitadas: Google Cloud IAM determina los permisos efectivos de cada identidad.

El usuario debe revisar los permisos solicitados antes de autorizar la conexión y mantener únicamente los accesos necesarios para su finalidad.

3. IAM, cuentas y mínimo privilegio

El usuario es responsable de administrar adecuadamente roles IAM, cuentas de servicio, identidades federadas y demás mecanismos de autorización vinculados a su entorno. Se recomienda aplicar el principio de mínimo privilegio, separar funciones y retirar permisos que ya no sean necesarios.

4. Credenciales y secretos

ScientificBrain Cloud Connector no requiere que el usuario entregue su contraseña de Google a Innova Space Education SpA. El usuario no debe introducir contraseñas, claves privadas, secretos, tokens de larga duración ni otras credenciales sensibles en campos no destinados expresamente a ello.

Cuando el flujo técnico utilice tokens, credenciales temporales o federación de identidades, estos deben protegerse conforme a las prácticas de seguridad aplicables y a la configuración del proveedor correspondiente.

5. Operaciones sobre Google Cloud

Algunas acciones pueden modificar infraestructura real, permisos, configuraciones, despliegues, recursos o costos. El usuario debe revisar las operaciones sensibles y mantener respaldos, controles de cambios y procedimientos de recuperación apropiados.

6. Seguridad

Innova Space Education SpA aplica medidas razonables para reducir riesgos técnicos, pero ningún sistema puede garantizar seguridad absoluta. El usuario debe proteger sus cuentas, habilitar controles adicionales cuando estén disponibles, supervisar actividad y revocar accesos ante cualquier indicio de compromiso.

7. Revocación y terminación del acceso

El usuario puede revocar la autorización OAuth desde la configuración de seguridad de su cuenta de Google. También puede retirar roles IAM, deshabilitar identidades o solicitar asistencia a contacto@innova-space-edu.cl. La revocación puede impedir inmediatamente nuevas operaciones que dependan de esa autorización.

8. Servicios y proveedores de terceros

ScientificBrain Cloud Connector puede depender de servicios, API, plataformas o clientes de terceros, incluidos Google Cloud y clientes compatibles con MCP. Su disponibilidad, cuotas, cambios, precios, términos y políticas son determinados por cada proveedor y pueden variar sin control de Innova Space Education SpA.

9. Costos

Las operaciones ejecutadas en Google Cloud pueden generar cargos en los proyectos o cuentas de facturación del usuario. El usuario es responsable de revisar precios, presupuestos, cuotas y alertas de facturación aplicables a sus recursos.

10. Uso prohibido

  • Acceder o intentar acceder a recursos sin autorización.
  • Eludir controles OAuth, IAM, seguridad o auditoría.
  • Utilizar credenciales de terceros sin autorización válida.
  • Emplear el servicio para actividades ilícitas, abusivas o que comprometan la seguridad de terceros.

11. Responsabilidad

ScientificBrain Cloud Connector se proporciona como herramienta de apoyo para operaciones autorizadas. En la medida permitida por la legislación aplicable, Innova Space Education SpA no será responsable de interrupciones de terceros, cambios de API, configuraciones incorrectas del usuario, pérdida de acceso, costos de Google Cloud ni efectos derivados de operaciones autorizadas por el usuario.
